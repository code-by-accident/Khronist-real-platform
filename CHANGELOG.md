# Журнал змін

Формат — [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/), версії — за [SemVer](https://semver.org/lang/uk/).

## [1.0.0] — 20.11

Перший випуск: MVP для Культурного хакатону OBRIO × МУР, трек «Історія».

### Додано

#### Розширення Chrome

- Бічна панель на ARCHIUM ЦДІАК України: розпізнавання шифру аркуша (архів, фонд, опис, справа, номер зображення), виділення фрагмента скану й надсилання його на читання.
- Результат читання: рядки з позначеними непевними словами, попередження про обрізаний текст, пошкоджений папір і бліде чорнило, текст сучасною орфографією, розкриті скорочення, переклад українською під рядками.
- Сутності (люди, місця, терміни, дати) як чипи; пояснення за довідковим корпусом із джерелом і ліцензією, переведення дат зі старого стилю в новий із днем тижня.
- Вкладка «Спитати»: чат про запис і його терміни, без джерела відповідає, що відповіді немає.
- Правка рядків із панеллю старих літер, збереження серії правок як однієї версії, розв'язання конфліктів рядок за рядком.
- Підтвердження транскрипції з підписом, цитата за ДСТУ 8302:2015, у Markdown або простим текстом.
- Вхід за кодом із листа, профіль із підписом, гаряча клавіша Alt + Shift + X.
- Показ уже прочитаного на аркуші.

#### API

- Читання фрагмента фоновою задачею з подіями SSE, кешем за хешем зображення, основною й резервною моделлю та повторами.
- Нормалізація, пошук сутностей, переклад українською.
- Версії транскрипцій, історія правок, підтвердження людиною з підписом, права підтверджувачів.
- Пояснення й чат лише за довідковим корпусом із перевіреними цитатами; пошук по корпусу зі словником варіантів, повнотекстовий і за триграмами.
- Commons: пошук із фільтрами архіву, фонду й років та курсорною пагінацією, стрічка нещодавно підтверджених, маршрут цитування.
- Ключі API для пакетного читання, ліміти частоти й добовий бюджет викликів моделі, адмін-маршрути завантаження корпусу.

#### Вебзастосунок

- Пошук у Commons на [app.khronist.org](https://app.khronist.org) зі стрічкою «Нещодавно підтверджені».

#### MCP-сервер

- Інструменти `transcribe`, `explain` і `search_sources` для AI-асистентів із підтримкою MCP.

#### Корпус і дані

- 151 стаття довідкового корпусу з Енциклопедичного словника Брокгауза й Ефрона та української Вікіпедії, словник варіантів написання імен і назв, каталог топонімів Київського повіту.
- Набір із 30 запитань для оцінки пояснень і чату, оцінка якості читання за еталонами.
- Демонстраційний фонд: 100 аркушів п'яти метричних книг і готові прочитання.

#### Інфраструктура й документація

- Дизайн-система `@khronist/ui`, пакети `@khronist/contracts` і `@khronist/prompts`.
- Розгортання API на Railway, CI з перевірками коду, `services/knowledge` і запуском на справжньому PostgreSQL.
- Документація: посібник користувача, довідник API, архітектура, конфігурація, Commons, корпус, розробка.

### Відомі обмеження

- Розширення працює лише на ARCHIUM ЦДІАК України, у Chrome Web Store його немає, встановлюється вручну.
- MCP-сервер запускається локально з клону репозиторію (stdio).
- Немає нотатника й завантаження власних сканів.
- Масового вивантаження даних Commons поки немає.
